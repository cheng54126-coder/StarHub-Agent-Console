# 星枢 Agent Console

**StarHub Agent Console** 是一个可自部署的本地 AI 助手控制台，用语音、MCP 和工作流能力把你的电脑变成个人 Agent 中枢。

项目以语音唤醒、字幕反馈、粒子球体交互为核心入口，集成 AI 模型配置、MCP 工具管理、网页搜索、屏幕读取和 Boss 求职工作台等能力，让用户可以通过自然语言调度本地工具、AI 服务和自动化工作流。

## 功能

- 本地 AI 对话与多供应商接口配置
- 语音输入、语音回复和字幕展示
- MCP 服务配置、同步和工具调用
- 屏幕读取与网页搜索交互入口
- Boss MCP 求职工作台：岗位搜索、详情展示、话术复制、状态流转和系统浏览器打开

## 运行

```bash
npm run dev
```

默认访问地址：

```text
http://127.0.0.1:8787
```

## 本地数据

运行时配置、聊天记录、MCP 配置和求职缓存默认保存在 `data/` 目录。该目录包含本地密钥和个人数据，已通过 `.gitignore` 排除，不应提交到仓库。

## 验证

```bash
npm run check
npm test
```
